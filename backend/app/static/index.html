System admin

  
Deploy & restart pulls the latest code from GitHub, installs Python packages,
    updates the database and restarts the app.
    Everyone is disconnected for a few seconds; a sync that is running stops and continues after the restart.
    If the new version does not start, the server goes back to the previous one.

Software releases

  
Releases arrive here by themselves from GitHub. On the development PC:
    python deploy/make_release.py --bump patch (or minor for new features), then
    git push origin main v1.0.1. GitHub builds the package and uploads it as a draft, or published if
    the repository variable TALLYCLOUD_AUTO_PUBLISH is true. Check a draft, then Publish: company admins
    download it from their portal, and activated servers install it from their Licence tab. Every update needs a
    new, higher version. You can still upload a package by hand below.

  

  

    Packs, signs and publishes the version this portal runs. The portal also does this by
      itself after every deploy of a new version.
