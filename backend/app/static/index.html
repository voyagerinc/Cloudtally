System admin

  

    
Update from licence server fetches the newest version your licence covers from
      Tally Cloud, checks that Voyager signed it, installs it and restarts. Settings and data stay as they are;
      if the new version does not start, the previous one comes back by itself. Everyone is disconnected for a
      minute or two.

    

    

      
      
    

    

  

  

  
Deploy & restart pulls the latest code from GitHub, installs Python packages,
    updates the database and restarts the app.
    Everyone is disconnected for a few seconds; a sync that is running stops and continues after the restart.
    If the new version does not start, the server goes back to the previous one.

Backup & restore

  

    
Move Tally Cloud, or some of its companies, to another server without reading everything
      from Tally again. On the other server, install Tally Cloud, update it to this version or later and sign in as
      super admin. Keep backup files safe: they contain your books.

Software releases

  
Releases arrive here by themselves from GitHub. On the development PC:
    python deploy/make_release.py --bump patch (or minor for new features), then
    git push origin main v1.0.1. GitHub builds the package and uploads it as a draft, or published if
    the repository variable TALLYCLOUD_AUTO_PUBLISH is true. Check a draft, then Publish: company admins
    download it from their portal, and activated servers install it from their Licence tab. Every update needs a
    new, higher version. You can still upload a package by hand below.

  

  

    Packs, signs and publishes the version this portal runs. The portal also does this by

Inbound failures

  
Vouchers that came from Tally but could not be saved, grouped by problem. Fix the cause, then
    Try again. A voucher corrected in Tally is read again by the next sync by itself.

  

    
    

  




  
Open a Tally company

  
Each Tally company gets its own ERP company with separate books. A newly linked company starts in
    shadow mode: it receives data from Tally, and nothing is written to Tally.
